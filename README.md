# 🌐 WebApi8

Projeto de estudo desenvolvido em ASP.NET Core para praticar conceitos fundamentais de APIs REST, integração com banco de dados e utilização do Entity Framework Core.

---

## Tecnologias Utilizadas

- C#
- .NET 8
- ASP.NET Core Web API
- Entity Framework Core
- SQL Server
- Swagger / Swashbuckle

---

## Funcionalidades

- CRUD básico
- Endpoints REST
- Integração com banco de dados
- Documentação com Swagger

---

## Como executar o projeto

### Clone o repositório

```bash
git clone https://github.com/zVilanova/WebApi8.git
```

### Acesse a pasta do projeto

```bash
cd WebApi8
```

### Configure a connection string

Edite o arquivo:

```bash
appsettings.json
```

### Execute as migrations

```bash
dotnet ef database update
```

### Execute o projeto

```bash
dotnet run
```

---

## 📖 Swagger

Após executar a aplicação, acesse:

```bash
https://localhost:7162/swagger
```

## 🎯 Objetivo do Projeto

Este projeto foi desenvolvido com foco em aprendizado prático de APIs REST utilizando ASP.NET Core e Entity Framework Core.
